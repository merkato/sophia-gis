# Wtyczki zainstalowane na tym serwerze

Każda wtyczka to katalog `plugins/<id>/` z manifestem `sophia-plugin.json`, montowany w kontenerze API
jako `/plugins`. Instalacja i aktualizacja: `scripts/server/plugin.sh`; włączanie i uprawnienia: panel
administratora → **Wtyczki**. Opis: [docs/WTYCZKI.md](../docs/WTYCZKI.md).

Zawartość katalogu (poza tym plikiem) nie trafia do repozytorium Sophii.
